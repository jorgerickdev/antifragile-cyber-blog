MÓDULO 01 — REDES BARE-METAL

🛡️ MISIÓN 01: Sniffer de Red Bare-Metal & Filtro Dinámico de Capa 4

Entorno: Ubuntu Linux | Lenguaje: Python 3 (Sockets Crudos & Sin Librerías Externas) | Capa: Enlace de Datos, Red y Transporte (L2 / L3 / L4).

📖 El Rol de los Sniffers en Ciberseguridad: Del Software Comercial al Bare-Metal

Un sniffer o analizador de paquetes es una herramienta fundamental en el ecosistema de la ciberseguridad que permite interceptar, examinar y auditar el tráfico de datos en bruto que transita a través de una interfaz de red. En el ámbito operativo, es utilizado por los equipos defensivos (Blue Team) para el monitoreo de tráfico anómalo, la detección de intrusiones y el análisis forense de incidentes, mientras que los equipos ofensivos (Red Team) lo emplean para la inspección de credenciales transmitidas en texto claro, el reconocimiento pasivo y el mapeo de servicios expuestos.

En la industria existen soluciones comerciales y automatizadas altamente consolidadas como Wireshark, Tcpdump o Tshark, las cuales ofrecen interfaces gráficas avanzadas y decodificadores automáticos preconstruidos. Sin embargo, la diferencia fundamental con el analizador programado en esta misión radica en el nivel de abstracción: mientras las herramientas comerciales ocultan la complejidad interna de los protocolos, desarrollar nuestro propio sniffer bare-metal desde cero en Python mediante Raw Sockets nos obligó a desmenuzar manualmente la trama byte por byte (Ethernet, IPv4 y TCP/UDP). Esta práctica hizo que el aprendizaje fuera verdaderamente profundo y antifrágil, pasando de la simple observación en una GUI a la comprensión física de cómo el kernel de Linux procesa y des-serializa cada paquete de red.

🧠 Fundamentos Técnicos: ¿Qué hace y cómo funciona un Sniffer?

A nivel de arquitectura de red, un sniffer bare-metal interactúa directamente con la pila de protocolos de Linux sin capas intermedias de abstracción:

🔌 Raw Sockets (AF_PACKET)

A diferencia de los sockets estándar que operan en Capa 4 (TCP/UDP), el uso de socket.AF_PACKET junto con socket.SOCK_RAW le indica al kernel de Linux que entregue las tramas Ethernet crudas completas (Capa 2), incluyendo las direcciones MAC físicas y los identificadores EtherType.

📡 Modo Promiscuo

Por defecto, la tarjeta de red descarta los paquetes cuyo destino no sea su propia dirección MAC. Activando el modo promiscuo (sudo ip link set dev <interfaz> promisc on), el adaptador procesa todo flujo electromagnético o eléctrico que circule por el medio físico local.

📦 Des-serialización Binaria

Mediante el módulo nativo struct de Python (struct.unpack), los paquetes recibidos en formato de bytes binarios son descompuestos mapeando la estructura exacta de las cabeceras Ethernet (14 bytes), IPv4 (20+ bytes) y la Capa de Transporte calculada dinámicamente mediante el offset IHL.

💻 Análisis del Código Fuente (`sniffer.py`)

A continuación se muestra el código fuente implementado en Python 3 puro. El programa valida privilegios de superusuario, configura la captura en crudo y aplica el offset dinámico del IHL (Internet Header Length) para calcular exactamente el inicio de las cabeceras TCP/UDP:

python3 sniffer.py 80 — Terminal Bare-Metal 
import socket
import struct
import sys

def main():
    # Validar argumento de puerto
    if len(sys.argv) < 2:
        print("Uso: sudo python3 sniffer.py ")
        sys.exit(1)
    filtro_puerto = int(sys.argv[1])

    try:
        # Abrir socket crudo en la familia AF_PACKET (Capa 2 / Ethernet)
        conn = socket.socket(socket.AF_PACKET, socket.SOCK_RAW, socket.ntohs(3))
    except PermissionError:
        print("[-] Error: Se requieren privilegios de administrador (sudo).", file=sys.stderr)
        sys.exit(1)
    except AttributeError:
        print("[-] Error: AF_PACKET solo está disponible en sistemas Linux.", file=sys.stderr)
        sys.exit(1)

    print(f"[+] Sniffer activo... Escuchando tráfico en el puerto {filtro_puerto}")

    while True:
        try:
            raw_data, addr = conn.recvfrom(65535)
        except KeyboardInterrupt:
            print("\n[+] Sniffer detenido por el usuario.")
            break

        if len(raw_data) < 14:
            continue

        # 1. Desempaquetado de la Cabecera Ethernet (14 bytes)
        eth_header = raw_data[:14]
        dest_mac, src_mac, eth_proto = struct.unpack('!6s6sH', eth_header)

        def format_mac(bytes_addr):
            return ':'.join(f'{b:02x}' for b in bytes_addr)

        # 2. Desempaquetado de IPv4 (EtherType 0x0800)
        if eth_proto == 0x0800 and len(raw_data) >= 34:
            ip_header_raw = raw_data[14:34]
            ip_data = struct.unpack('!BBHHHBBH4s4s', ip_header_raw)

            version_ihl = ip_data
            version = version_ihl >> 4
            ihl = (version_ihl & 0xF) * 4  # Offset dinámico de la cabecera IP
            ttl = ip_data[2]
            protocol = ip_data[3]
            src_ip = socket.inet_ntoa(ip_data[4])
            dest_ip = socket.inet_ntoa(ip_data[5])

            proto_name = "OTRO"
            if protocol == 1:
                proto_name = "ICMP"
            elif protocol == 6:
                proto_name = "TCP"
            elif protocol == 17:
                proto_name = "UDP"

            src_port = dest_port = None

            # 3. Offset Dinámico y Extraer Puertos de Capa 4
            if protocol == 6 and len(raw_data) >= 14 + ihl + 20:
                tcp_header = raw_data[14+ihl:14+ihl+20]
                src_port, dest_port = struct.unpack('!HH', tcp_header[:4])
            elif protocol == 17 and len(raw_data) >= 14 + ihl + 8:
                udp_header = raw_data[14+ihl:14+ihl+8]
                src_port, dest_port = struct.unpack('!HH', udp_header[:4])

            # 4. Filtrado por puerto especificado
            if src_port == filtro_puerto or dest_port == filtro_puerto:
                print(f"\n[+] Trama Detectada:")
                print(f"    |- MAC Origen: {format_mac(src_mac)} -> MAC Destino: {format_mac(dest_mac)}")
                print(f"    |- IP Versión: {version} | Tamaño Cabecera: {ihl} bytes | TTL: {ttl}")
                print(f"    |- Protocolo: {proto_name} ({protocol})")
                print(f"    |- Ruta: {src_ip}:{src_port} -> {dest_ip}:{dest_port}")

if __name__ == "__main__":
    main()

🛡️️ Fricción Deliberada, Factores Rompe-Intuición y Blue Team

🧠 Factor Rompe-Intuición (System 2 Break)

  • Privilegios del Kernel: La ausencia inicial de paquetes no se debió a un error en el código de Python, sino a la protección del kernel de Linux que impide a usuarios no privilegiados abrir sockets AF_PACKET o alterar el estado promiscuo del hardware.
  • Diferenciación de Interfaces: El tráfico de pruebas locales (ej. ssh localhost) circula a través de la interfaz virtual loopback (lo) con direcciones MAC nulas (00:00:00:00:00:00), a diferencia del tráfico de la tarjeta física (eno1) que refleja la transmisión real en el medio.

🩹 Mitigación & OpSec (Perspectiva Defensiva)

  • Desactivación de Modo Promiscuo: El modo promiscuo debe desactivarse inmediatamente al concluir el diagnóstico (sudo ip link set dev eno1 promisc off) para evitar sobrecargas de procesamiento por tramas de broadcast y prevenir la detección pasiva por latencia ICMP.
  • Detección SOC: Las llamadas a sockets crudos no autorizados en la infraestructura deben monitorearse mediante auditores de eventos del kernel como eBPF o Auditd, generando alertas cuando procesos no firmados soliciten la familia de protocolos AF_PACKET.

# 🛡️ Antifragile Cyber Labs

## 📌 Descripción del Proyecto
Portal web y bitácora técnica de arquitectura de red, ciberseguridad defensiva/ofensiva y monitoreo SOC. Proyecto desarrollado para la **Actividad 1** de la asignatura **Desarrollo de Aplicaciones de Red (DAR)**.

---

## 📁 Arquitectura del Repositorio
El proyecto sigue una estructura desacoplada y modular (HTML5 semántico, CSS3 Cyber Dark independiente y JS local):

```text
dar_act1/
├── login.html                   # Módulo de Autenticación de Operadores
├── dashboard.html               # Consola Principal de Operaciones (SOC)
├── mision-01.html               # Módulo 01: Estructura & Semántica HTML5
├── mision-02.html               # Módulo 02: Diseño & Estilos Cyber Dark
├── mision-03.html               # Módulo 03: Control de Versiones & SSH
├── assets/
│   ├── css/
│   │   ├── global.css           # Variables de Tema y Reglas Base
│   │   ├── login.css            # Estilos Exclusivos del Login
│   │   └── dashboard.css        # Estilos del Panel SOC y Tarjetas
│   ├── js/
│   │   └── login.js             # Lógica de Validación de Credenciales
│   └── img/                     # Recursos Gráficos e Identidad Visual
└── README.md                    # Documentación Técnica del Proyecto
